### 2. File Upload API Endpoint

**File:** `src/app/api/upload/route.ts`

**POST /api/upload** - Upload new file
- Multipart form data
- Auto-validation
- Database storage
- Permission: `file:upload`

**GET /api/upload** - List files
- Paginated (default 20 per page)
- Sorted by upload date
- Includes metadata
- Permission: `file:view`

**DELETE /api/upload?id={fileId}** - Delete file
- Remove from database
- Permission: `file:manage`

**Response Format:**
```json
{
  "id": "uuid",
  "originalName": "document.pdf",
  "fileName": "1692806400000-a1b2c3d4.pdf",
  "filePath": "/uploads/1692806400000-a1b2c3d4.pdf",
  "fileSize": 1024000,
  "fileSizeFormatted": "1 MB",
  "mimeType": "application/pdf",
  "category": "document",
  "uploadedAt": "2026-08-23T10:06:00Z",
  "uploadedBy": "Principal Admin"
}
```
