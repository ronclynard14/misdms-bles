### 2. Email API Endpoint

**File:** `src/app/api/notifications/email/route.ts`

**POST /api/notifications/email** - Send email
- Request body: `{ to, subject, template, data }`
- Permission: `notification:send`
- Returns: `{ success: true, messageId: "..." }`
- Logs notification in database

**GET /api/notifications/email** - View email history
- Paginated (default 20 per page)
- Sorted by sent date
- Permission: `notification:view`

**Response Format:**
```json
{
  "notifications": [
    {
      "id": "uuid",
      "type": "EMAIL",
      "recipient": "user@school.edu",
      "template": "grade_posted",
      "status": "SENT",
      "sentAt": "2026-08-23T10:13:00Z",
      "sentBy": { "name": "System" },
      "metadata": { ... }
    }
  ],
  "pagination": {
    "page": 1,
    "pageSize": 20,
    "total": 150,
    "totalPages": 8
  }
}
```
