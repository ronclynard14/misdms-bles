### 2. Settings API Endpoint

**File:** `src/app/api/settings/route.ts`

**GET /api/settings**
- Fetch all settings or by category
- Returns grouped settings by category
- Permission: `settings:view`
- Response:
```json
{
  "settings": [...],
  "grouped": {
    "school": [...],
    "academic": [...],
    ...
  },
  "categories": ["school", "academic", ...]
}
```

**PATCH /api/settings**
- Update a single setting
- Permission: `settings:manage`
- Request:
```json
{
  "key": "school_name",
  "value": "New School Name"
}
```
- Validates before updating
- Returns updated setting

## 🚀 Extensibility

### To Add New Settings:

1. Add to `DEFAULT_SETTINGS` in `settings.ts`:
```typescript
new_setting: {
  value: "default_value",
  description: "Setting description",
  dataType: "string" | "number" | "boolean",
  category: "school" | "academic" | ...
}
```

2. Add validation in `validateSettingValue()` if needed

3. Settings automatically appear in UI

### To Add New Categories:

1. Add to `CATEGORY_LABELS` in page.tsx
2. Update `category` type in settings.ts
3. Settings automatically grouped
