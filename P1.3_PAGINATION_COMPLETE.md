## Key Features

**Query Parameters:**
- `?page=1` - Page number (default: 1)
- `?pageSize=20` - Items per page (default: 20, max: 100)

**Response Format:**
```json
{
  "data": [...],
  "pagination": {
    "currentPage": 1,
    "pageSize": 20,
    "totalItems": 150,
    "totalPages": 8,
    "hasNextPage": true,
    "hasPreviousPage": false
  }
}
```

**UI Features:**
- First/Previous/Next/Last buttons
- Direct page number selection (5 visible pages)
- Page size dropdown (10/20/50/100)
- Item range display (e.g., "Showing 1-20 of 150")
- Loading states
- Disabled boundary conditions
